# 25 — Product roadmap

> **Status:** Gate-driven options, not delivery promises
> **Planning unit:** evidence and exit criteria, not calendar theatre
> **Current state:** Phase 0 desk research/document draft; production implementation blocked

## Roadmap principles

- Sweden and Grade 8 first.
- Complete the simplest trustworthy end-to-end loop before adding breadth.
- Review competitors before every major feature using GREEN/YELLOW/BLUE/RED.
- A failed gate stops dependent work; do not “ship and learn” with avoidable harm to minors.
- Technical work before validation is limited to disposable prototypes and source/security feasibility spikes with no personal data.
- Full production rollout follows all gates, not just code completion.
- No agents, microservices, graph database, native apps or country expansion without measured need.

## Phase 0 — evidence and architecture package (current)

### Deliver

- 25 review artifacts;
- source register, decision log and gate review;
- competitor/problem/legal/data desk evidence;
- explicit unknowns, risks and no-build boundaries.

### Exit

- Founder/product intent review;
- independent SYV, privacy, security and accessibility critique assigned;
- revisions accepted for primary research;
- production build remains stopped.

### Current decision

**Desk evidence supports continuing to discovery, but Gate 1 is not passed.**

## Phase 0.5 — problem discovery

### Learn

- Does the exact confusion→action job recur for Grade 8/9 students?
- Which part is hardest: self-understanding, options, rules, comparison, parent/SYV conversation or action?
- What do existing official/commercial tools already solve?
- Does the no-label, branch, source and one-action proposition improve the experience?

### Discovery outputs

- approved research protocol and 18+ student / 6+ parent / 6+ SYV sessions;
- top jobs, counter-evidence and narrowed persona/context;
- updated PRD/scope/journeys/risk/business hypotheses;
- competitor task benchmark.

### Gate 1 — problem validity

Pass only with current primary evidence meeting pre-registered criteria. Otherwise stop/reposition/research.

## Phase 1 — clickable comprehension prototype

### Build (disposable, no production data)

- Swedish low/high-fidelity mobile prototype for JAG → UTFORSKA → MIN VÄG → ALTERNATIV → NÄSTA;
- synthetic eligibility eligible/not-yet/unknown states;
- separate recommendation dimensions;
- source/forecast/conflict displays;
- parent preview/revoke and SYV brief concepts;
- path diagram + accessible list.

### Test

Three rounds with diverse students, assistive technology, parents and SYVs. Compare with official/existing alternatives. Revise content/design system.

### Gate 2 — comprehension

Students can independently explain dimensions, source/date/uncertainty, setback and sharing control; accessibility target met.

### Gate 3 — MVP value

The complete prototype produces meaningful clarity/options/path/next action better enough than current alternatives, without added pressure. If only one workflow matters, narrow the MVP.

## Phase 2 — trusted foundation and feasibility

After all 25 artifacts are reviewed and Gates 1–3 pass, create only the implementation needed for a controlled pilot.

### Track A — public catalogue/provenance

- modular monolith, PostgreSQL claims/temporal model;
- Skolverket source registry/adapters, Gy25 programme catalogue, school/offering pilot regions;
- source sheets, coverage/freshness/conflict and correction workflow;
- 30-day ingestion rehearsal and rollback.

### Track B — rules/recommendations/paths

- constrained rule DSL and approved golden corpus;
- profile observations and self-reported subject results;
- deterministic recommendation dimensions/diversity;
- graph relationships and branchable path snapshots;
- finite next-action catalogue;
- reviewed templates first; AI adapter remains off until it proves incremental value.

### Track C — minor-safe platform

- anonymous/session/account identity, passkey/magic-link usability;
- row/tenant/share access controls;
- export/delete/restrict/reset;
- security/observability with redaction;
- DPIA, vendor/transfer/contracts;
- WCAG implementation and manual tests;
- incident/safeguarding/support/restore exercises.

### Gate 4 — recommendation quality

Rules, separated dimensions, explanations, paths, alternatives and fairness pass synthetic/domain/user quality thresholds; no opaque score or unsupported critical claim.

### Gate 5 — minor safety

DPIA/legal roles, child understanding, sharing, security/accessibility/safeguarding, vendors/transfers, deletion and incident readiness approved; no unresolved critical/high issue.

### Gate 6 — reliable data

Authority-first source pipeline demonstrates measured coverage/freshness/correction/rollback for pilot fields/regions; missing/conflicts degrade honestly.

## Phase 3 — controlled student MVP pilot

Only after Gates 4–6 and pilot readiness sign-off.

### Release

- anonymous/account start;
- living editable profile;
- programme/occupation/pilot-region offering explore;
- eligibility/recommendation explanation;
- My Path/compare/next action;
- source display/reporting;
- student-created printable SYV brief (sharing may start with controlled subset);
- no parent standing access, AI chat, reviews, ads, application or integrations.

### Operate

- 2–3 diverse partners, 80–150 invited, target ≥40 activated;
- 8–12 week feasibility window;
- first-party minimal analytics and separate voluntary research;
- daily/weekly source/safety/support monitoring and clear stop criteria.

### Gate 7 — usage

Students use the complete loop for a purposeful outcome and useful next action—not just log in. Operational/support burden remains acceptable and guardrails hold.

If usage fails: diagnose problem, onboarding, data, value and context; do not add gamification.

## Phase 4 — parent and SYV trust pilots

### Parent slice

- expiring student-scoped share, exact preview, access history/revoke;
- conversation prompts and visible comments;
- no grades/private history/alerts by default.

### Gate 8 — parent trust

Students and parents understand control/scope; conversation helps without increased pressure or covert monitoring. Pause parent mode if not.

### SYV slice

- organisation identity and just-in-time student share;
- source/rule trace and correction;
- accepted-suggestion next action;
- aggregate service report only, no named risk/compliance view.

### Gate 9 — SYV utility

Brief improves preparation/conversation without replacing professional judgement, adding unsustainable work or becoming a hidden assessment.

## Phase 5 — sustainability and production decision

### Validate

- buyer/procurement willingness beyond free pilot;
- standard contract/controller/deployment model;
- cost-to-serve including data stewardship/compliance/support;
- source/vendor continuity and national coverage economics;
- support/security/accessibility operating model;
- funded downside plan.

### Gate 10 — sustainability

Approve scaled Swedish production only if outcome/trust gates and viable conflict-free economics all pass. Otherwise remain a small public pilot, narrow to a useful component, seek public/partner funding, or stop.

## Phase 6 — Sweden gymnasium depth (only after Gate 10)

Potential sequence based on evidence:

1. Expand school/offering/admission coverage region by region with public coverage map.
2. Add verified open-house feeds and coarse transit in areas meeting data/privacy thresholds.
3. Add transparent what-if scenarios and stronger resilience branches.
4. Improve easy-Swedish/approved language support.
5. Mature school/municipality onboarding and correction operations.
6. Evaluate carefully scoped institution integrations; no official application replacement.

Each capability receives fresh competitor review and risk/gate impact assessment.

## Phase 7 — next education transitions

Only when the gymnasium loop is proven and a new discovery phase passes:

- university/college exploration using UHR authority data;
- YH routes using MYH data;
- adult/bridging routes where verified;
- higher-education eligibility transition for Gy25/Gy11;
- study finance links/context from CSN;
- older-user privacy/content adaptations.

Do not merely append a giant catalogue. Redesign decisions and handoffs for the new life stage.

## Phase 8 — work and continuing development

Separate future discovery:

- entry-to-work transitions and verified skill/task maps;
- career change/continuing education;
- changing qualification and labour signals;
- adult accounts and distinct legal/safety model.

Still exclude guaranteed employment, salary prediction, paid ranking and data brokerage.

## Country expansion—not roadmapped

The schema preserves `country_code`, framework/rule/source/terminology boundaries. No second country work begins until Sweden has passed gates and country-specific research, legal, source and education modelling are funded. Reuse architecture, not Swedish assumptions.

## Dependency map

```text
25-document review
  → Gate 1 problem
    → Gate 2 comprehension
      → Gate 3 MVP value
        → pilot implementation
          → Gate 4 recommendation quality
          → Gate 5 minor safety
          → Gate 6 reliable data
            → student pilot → Gate 7 usage
              → parent pilot → Gate 8 trust
              → SYV pilot → Gate 9 utility
                → buyer/economics → Gate 10 sustainability
                  → Swedish production depth
```

Gates 4–6 can progress in parallel but all must pass before live minor-data pilot.
